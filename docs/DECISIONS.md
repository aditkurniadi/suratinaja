# Keputusan Produk: SuratinAja

Dokumen ini mencatat jawaban pengguna sesuai pilihan dan teks yang diberikan. Label `Dijawab` berarti opsi dipilih, bukan berarti semua detail dalam opsinya sudah ditentukan. Deskripsi opsi adalah konteks, bukan izin untuk mengarang nominal, SLA, atau kebijakan. Jika detail belum eksplisit, tandai `TBD` pada spesifikasi turunannya.

## DEC-001 — Bagaimana pengelolaan template surat (.docx) di dalam sistem?

**Status:** Dijawab

**Jawaban pengguna:** Keduanya (Global + Upload Mandiri): Workspace dapat menggunakan template global atau mengunggah template sendiri sesuai kebutuhan.

## DEC-002 — Format penomoran surat seperti apa yang harus didukung sistem?

**Status:** Dijawab

**Jawaban pengguna:** Format Kustom per Workspace: Setiap workspace dapat menentukan sendiri pola penomoran (misal: nomor urut, kode, bulan, tahun) melalui pengaturan.

## DEC-003 — Bagaimana cara memasukkan data penerima untuk pembuatan surat massal?

**Status:** Dijawab

**Jawaban pengguna:** Keduanya (Manual + Upload): Mendukung input manual dan upload file untuk fleksibilitas maksimal.

## DEC-004 — Bagaimana alur persetujuan dan tanda tangan surat di sistem?

**Status:** Dijawab

**Jawaban pengguna:** Tanda Tangan Fisik (Cetak): Surat dicetak, ditandatangani basah, lalu status diubah manual ke 'Selesai' oleh sekretaris.

## DEC-005 — Ketika surat yang sudah memiliki nomor direvisi, bagaimana sistem harus menangani nomor lama?

**Status:** Dijawab

**Jawaban pengguna:** Manual Assign oleh Sekretaris: Sekretaris dapat memilih untuk menggunakan nomor baru atau tetap, dengan catatan alasan revisi.
